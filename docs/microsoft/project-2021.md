# Microsoft Project Professionnel 2021 — guide d'activation

## Informations produit

| Champ | Valeur |
|---|---|
| **Type de licence** | Clé de produit |
| **Durée** | Perpétuelle |
| **Appareils** | 1 PC |
| **Compatibilité** | Windows 10 et 11 — **Windows uniquement**, pas de version macOS |
| **Livraison** | Par courriel, sous 24 h ouvrées après confirmation du paiement |
| **Garantie** | Clé remplacée si elle ne fonctionne pas ; remboursée si le remplacement échoue |

!!! info "Ce que vous recevez"

    Un courriel contenant votre **clé de produit** de 25 caractères, le lien
    de téléchargement, et ce guide.

!!! warning "Project s'installe à côté d'Office, pas à sa place"

    Project est une application distincte : elle ne remplace ni Word ni Excel
    et ne les désinstalle pas.

    En revanche, **Project et Office doivent partager la même technologie
    d'installation**. Si votre Office est en version « Démarrer en un clic »
    (le cas de toutes les versions récentes), Project doit l'être aussi — ce
    qui est le cas de la version que nous fournissons.

    Si l'installation échoue en mentionnant un conflit, écrivez-nous : c'est
    presque toujours cette cause, et elle se règle en quelques minutes.

!!! success "À la fin de ce guide"

    - Project ouvert et utilisable, avec vos diagrammes de Gantt
    - La mention **« Produit activé »** dans **Fichier → Compte**

---

## Étape 1 — Enregistrer votre clé

Rendez-vous sur **[setup.office.com](https://setup.office.com)**, connectez-vous
avec un compte Microsoft, puis saisissez la clé reçue.

Notez bien ce compte : votre licence y est rattachée, et c'est par lui que
vous réinstallerez Project sans ressaisir la clé.

## Étape 2 — Télécharger et installer

Lancez le téléchargement proposé après l'enregistrement, puis exécutez le
fichier obtenu. L'installation prend quelques minutes.

## Étape 3 — Vérifier

Ouvrez **Project** → **Fichier → Compte**.

Sous *Informations sur le produit*, vous devez lire **« Produit activé »**.

## Questions fréquentes

??? question "Project fonctionne-t-il sur Mac ?"

    Non. Microsoft ne publie pas Project pour macOS. Cette licence est
    exclusivement Windows.

??? question "Puis-je ouvrir un fichier Project reçu par un collègue ?"

    Oui, si le fichier `.mpp` a été créé avec Project 2021 ou une version
    antérieure. Un fichier produit par une version plus récente peut ne pas
    s'ouvrir.

??? question "Faut-il Office pour utiliser Project ?"

    Non, Project fonctionne seul. Mais l'export vers Excel et l'envoi par
    Outlook sont plus commodes si Office est présent.

??? question "L'installation échoue en parlant d'un conflit."

    C'est le cas décrit dans l'avertissement plus haut : Office et Project
    installés avec deux technologies différentes. Contactez-nous, c'est une
    manipulation simple mais qu'il vaut mieux faire guidé.
