# Kaspersky Plus — guide d'activation

## Informations produit

| Champ | Valeur |
|---|---|
| **Type de licence** | Code d'activation |
| **Durée** | 1 an |
| **Appareils** | 1 |
| **Compatibilité** | Windows, macOS, Android, iOS |
| **Livraison** | Par courriel, sous 24 h ouvrées après confirmation du paiement |
| **Garantie** | Clé remplacée si elle ne fonctionne pas ; remboursée si le remplacement échoue |

!!! info "Ce que vous recevez"

    Un courriel contenant votre **code d'activation** au format
    `XXXXX-XXXXX-XXXXX-XXXXX`, le lien de téléchargement officiel, et ce guide.

    Vérifiez votre dossier **courrier indésirable**. Si rien n'est arrivé sous
    24 h ouvrées, écrivez-nous — voir [Assistance](#assistance).

!!! warning "À faire avant de commencer"

    - **Désinstallez tout autre antivirus** déjà présent sur l'appareil. Deux
      antivirus qui tournent ensemble se bloquent mutuellement et ralentissent
      la machine. Windows Defender, lui, se désactive tout seul.
    - Prévoyez une **connexion internet** : l'activation se fait auprès des
      serveurs de Kaspersky.
    - Gardez votre code d'activation sous la main. **Ne le communiquez à
      personne** : il n'est utilisable qu'une fois.

!!! success "À la fin de ce guide"

    - Kaspersky Plus est installé et **actif**
    - La fenêtre principale affiche la date d'expiration de votre licence
    - Votre code est rattaché à un compte My Kaspersky, ce qui vous permet de
      le retrouver si vous changez d'appareil

## Étape 1 — Télécharger Kaspersky

Rendez-vous sur le site officiel : **[kaspersky.fr](https://www.kaspersky.fr/downloads)**

Choisissez **Kaspersky Plus** et le système de votre appareil (Windows, macOS,
Android ou iOS), puis lancez le téléchargement.

!!! danger "N'installez jamais Kaspersky depuis un autre site"

    Les versions trouvées sur des sites de téléchargement tiers sont
    fréquemment modifiées. Un antivirus falsifié est pire que pas d'antivirus
    du tout : vous lui donnez les pleins pouvoirs sur votre machine.

## Étape 2 — Installer

Ouvrez le fichier téléchargé et laissez l'installation se dérouler. Elle prend
quelques minutes et peut demander un redémarrage.

Sur Windows, une fenêtre de contrôle de compte d'utilisateur s'affiche :
acceptez, c'est normal pour un antivirus.

## Étape 3 — Saisir le code d'activation

À la première ouverture, Kaspersky propose d'activer le produit.

1. Cliquez sur **Saisir le code d'activation** (ou **J'ai un code d'activation**)
2. Recopiez le code reçu par courriel, tirets compris
3. Validez

!!! tip "Copiez-collez plutôt que de recopier"

    La plupart des échecs d'activation viennent d'une confusion entre le
    chiffre **0** et la lettre **O**, ou entre **1** et **I**. Copiez le code
    depuis le courriel et collez-le directement.

Kaspersky contacte ses serveurs et valide la licence. L'opération dure quelques
secondes.

## Étape 4 — Rattacher la licence à un compte My Kaspersky

Cette étape est facultative, mais **nous la recommandons fortement**.

1. Dans Kaspersky, ouvrez **Mon compte Kaspersky**
2. Créez un compte, ou connectez-vous si vous en avez déjà un
3. Votre licence apparaît alors dans votre espace sur
   [my.kaspersky.com](https://my.kaspersky.com)

Sans ce rattachement, la perte du courriel contenant votre code signifie la
perte de votre licence. Avec lui, vous la retrouvez depuis n'importe quel
navigateur.

---

## Vérifier que l'activation a réussi

Ouvrez Kaspersky. En bas de la fenêtre principale, vous devez lire une mention
du type :

> **La licence est valide jusqu'au …**

Si vous voyez à la place *« La licence a expiré »* ou *« Version d'essai »*,
l'activation n'a pas abouti. Reprenez l'étape 3, ou consultez la FAQ.

## Questions fréquentes

??? question "Puis-je installer Kaspersky sur plusieurs appareils ?"

    Non. Cette licence couvre **un seul appareil**. Installer le même code sur
    un deuxième appareil désactivera le premier.

    Si vous avez besoin de couvrir plusieurs appareils, écrivez-nous : des
    licences multi-postes existent.

??? question "Je change de téléphone ou d'ordinateur. Que faire ?"

    Désinstallez Kaspersky de l'ancien appareil, puis installez-le sur le
    nouveau et saisissez le même code. La licence suit l'appareil, pas la
    machine d'origine.

    Si vous avez rattaché la licence à un compte My Kaspersky, vous retrouverez
    le code directement dans votre espace.

??? question "Mon code est refusé. Pourquoi ?"

    Dans l'ordre de fréquence :

    1. **Erreur de saisie** — copiez-collez le code plutôt que de le recopier.
    2. **Mauvais produit** — un code Kaspersky Plus ne s'active pas sur
       Kaspersky Standard ou Premium. Vérifiez la version téléchargée.
    3. **Code déjà utilisé** sur un autre appareil.
    4. **Pas de connexion** au moment de l'activation.

    Si rien de tout cela ne s'applique, contactez-nous : nous remplaçons la clé.

??? question "Que se passe-t-il au bout d'un an ?"

    Kaspersky vous prévient à l'approche de l'échéance. La protection s'arrête
    à la date d'expiration ; le logiciel reste installé et se réactive dès
    qu'un nouveau code est saisi.

    Vous pouvez renouveler chez nous ou directement chez Kaspersky.

??? question "Dois-je garder Windows Defender activé ?"

    Non. Windows désactive automatiquement Defender quand un antivirus tiers
    prend le relais. C'est le comportement attendu, il n'y a rien à faire.
