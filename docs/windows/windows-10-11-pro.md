# Windows 10/11 Professionnel — guide d'activation

| Champ | Valeur |
|---|---|
| **Type de licence** | Clé de produit |
| **Durée** | Perpétuelle |
| **Appareils** | 1 PC |
| **Compatibilité** | Windows 10 Professionnel · Windows 11 Professionnel |
| **Livraison** | Par courriel, sous 24 h ouvrées après confirmation du paiement |
| **Garantie** | Clé remplacée si elle ne fonctionne pas ; remboursée si le remplacement échoue |

!!! info "Ce que vous recevez"

    Un courriel contenant votre **clé de produit** au format
    `XXXXX-XXXXX-XXXXX-XXXXX-XXXXX` et ce guide.

    Vérifiez votre dossier **courrier indésirable**. Si rien n'est arrivé sous
    24 h ouvrées, écrivez-nous — voir [Assistance](#assistance).

!!! warning "Vérifiez d'abord quelle édition est installée"

    Cette clé active **Windows Professionnel**. Elle ne fonctionnera pas sur
    Windows **Famille** (Home).

    Pour savoir où vous en êtes : ++windows+pause++, ou
    **Paramètres → Système → Informations système**. L'édition est indiquée
    en clair.

    Si vous êtes en Famille, il faut d'abord passer en Professionnel — voir la
    question correspondante dans la [FAQ](#questions-frequentes).

    Une **connexion internet** est également nécessaire : Windows valide la clé
    auprès des serveurs de Microsoft.

!!! success "À la fin de ce guide"

    - La mention **« Windows est activé »** dans les paramètres d'activation
    - Plus aucun filigrane ni rappel d'activation à l'écran
    - Toutes les fonctions Professionnel disponibles : BitLocker, Bureau à
      distance, Hyper-V, stratégies de groupe, personnalisation complète

## Étape 1 — Ouvrir les paramètres d'activation

Le chemin diffère selon la version :

=== "Windows 11"

    **Paramètres** → **Système** → **Activation**

=== "Windows 10"

    **Paramètres** → **Mise à jour et sécurité** → **Activation**

Raccourci valable sur les deux : ++windows+i++ pour ouvrir les Paramètres.

## Étape 2 — Saisir la clé de produit

Dépliez **État de l'activation**, puis cliquez sur **Modifier la clé de
produit** (ou **Changer la clé de produit**).

Saisissez les 25 caractères reçus par courriel.

!!! tip "Copiez-collez plutôt que de recopier"

    Les erreurs de saisie sont la première cause d'échec : le chiffre **0** et
    la lettre **O** se ressemblent, comme **1** et **I**. Collez la clé
    directement depuis le courriel — les tirets sont ajoutés automatiquement.

## Étape 3 — Laisser Windows valider

Cliquez sur **Suivant**, puis sur **Activer**.

Windows contacte les serveurs de Microsoft et vérifie la clé. L'opération dure
quelques secondes.

---

## Vérifier que l'activation a réussi

Retournez dans **Paramètres → Système → Activation**. Vous devez lire :

> **État de l'activation : Actif**
> Windows est activé avec une licence numérique

Le filigrane « Activer Windows » en bas à droite de l'écran disparaît. S'il
persiste, redémarrez l'ordinateur.

## Lier la licence à votre compte Microsoft

Cette étape est facultative, mais **elle vous évitera de racheter une licence
un jour**.

1. **Paramètres** → **Comptes** → **Vos informations**
2. Choisissez **Se connecter avec un compte Microsoft à la place**
3. Connectez-vous, ou créez un compte

Windows associe alors votre licence à ce compte : c'est ce qu'on appelle une
**licence numérique**. En cas de réinstallation, Windows se réactive tout seul
dès que vous vous connectez avec ce compte — sans avoir à ressaisir la clé.

!!! note "Pourquoi cela compte"

    Une clé de produit est un bout de papier : perdu, il est perdu. Une licence
    numérique est rattachée à votre identité Microsoft et vous suit. C'est cinq
    minutes aujourd'hui contre un rachat de licence plus tard.

## Questions fréquentes

??? question "Je suis sur Windows Famille. Comment passer en Professionnel ?"

    Il faut d'abord basculer l'édition, puis activer avec votre clé.

    Windows propose ce changement depuis **Paramètres → Système → Activation
    → Mettre à niveau votre édition de Windows**. Une clé générique de
    passage à Pro, publiée par Microsoft, permet de faire la bascule sans
    activer — votre vraie clé sert ensuite à l'activation.

    Écrivez-nous : nous vous guidons, c'est inclus dans votre achat.

??? question "Puis-je utiliser cette clé sur deux ordinateurs ?"

    Non. Une clé couvre **un seul PC**. Une deuxième activation sera refusée
    par Microsoft.

??? question "Je change d'ordinateur. Puis-je transférer ma licence ?"

    Cela dépend du type de licence. Une licence **Retail** est transférable —
    désactivez l'ancien PC, puis activez le nouveau avec la même clé. Une
    licence **OEM** reste liée à la machine sur laquelle elle a été activée.

    Écrivez-nous en indiquant votre numéro de commande : nous vous dirons
    quelle licence vous détenez.

??? question "J'ai changé de carte mère et Windows s'est désactivé."

    Microsoft considère un changement de carte mère comme un nouvel
    ordinateur. Si vous aviez lié la licence à votre compte Microsoft, utilisez
    **Paramètres → Activation → Résolution des problèmes → J'ai changé de
    matériel récemment** : Windows retrouve votre licence.

    Sans ce rattachement, contactez-nous.

??? question "Erreur 0xC004C003 ou 0xC004F050 — que faire ?"

    Ces codes signifient que le serveur Microsoft a refusé la clé. Les causes
    les plus fréquentes :

    1. **Édition incorrecte** — clé Pro saisie sur Windows Famille ;
    2. **Erreur de saisie** — copiez-collez plutôt que de recopier ;
    3. **Pas de connexion** internet au moment de l'activation.

    Si aucune de ces causes ne s'applique, contactez-nous : nous remplaçons
    la clé.

??? question "Dois-je réinstaller Windows pour utiliser cette clé ?"

    Non. La clé s'applique sur une installation existante, sans rien effacer.
    Vos fichiers, vos programmes et vos réglages restent en place.
